# Memory × 自进化评估 × 教学 Agent 阅读路线

## 缺口审计结论

原论文库对多 Agent 协作、共享记忆、分层记忆和通信机制覆盖较完整，但对拟研究主线的关键因果链覆盖不足：

1. 如何依据任务反馈控制写入、合并、更新、删除与遗忘；
2. 如何把教学效果或动态 rubric 转化为记忆效用信号；
3. 如何在长时间跨度、结构组织、知识失效和冲突条件下评测；
4. 如何把个体轨迹抽象为可迁移的 workflow、subtask、function 或教学 skill；
5. 如何用版本化 learner model 支撑长期个性化教学。

本轮新增的 27 篇论文针对以上五个缺口。`研究方向缺口审计.csv` 中的 S/A/B 表示与当前选题的相关优先级，不表示论文的绝对学术影响力。

## 第一阶段：先确定评测对象

优先读：

- *Evaluating Memory in LLM Agents via Incremental Multi-Turn Interactions*（MemoryAgentBench，ICLR 2026）
- *LongMemEval: Benchmarking Chat Assistants on Long-Term Interactive Memory*（ICLR 2025）
- *LongMemEval-V2: Evaluating Long-Term Agent Memory Toward Experienced Colleagues*
- *Evaluating Memory Structure in LLM Agents*（StructMemEval）
- *Evaluating Very Long-Term Conversational Memory of LLM Agents*（LoCoMo，ACL 2024）
- *STALE: Can LLM Agents Know When Their Memories Are No Longer Valid?*

目标是把 susuAgent 的评测拆成：准确检索、学生状态更新、长期理解、结构组织、知识失效、冲突解决、拒答/澄清、延迟与 token 成本。

## 第二阶段：建立生命周期方法轴

优先读：

- *Memory-R1*：把 ADD、UPDATE、DELETE、NOOP 明确建模为可学习操作。
- *Mem-α*：用下游任务正确率训练记忆构建。
- *Memory as a Controlled Process*（MemCon）：从任务反馈学习检索、计划复用、合并和遗忘。
- *What Deserves Memory*（ACL 2026）：以未来效用/可预测性决定保留内容。
- *Mem0* 与 *Zep*：作为实用结构化记忆和时间版本化基线。

建议先实现统一接口：`WRITE / MERGE / UPDATE / DEPRECATE / FORGET / RETRIEVE`，再让不同控制器共享同一存储后端，避免把“存储结构改进”和“控制策略改进”混为一谈。

## 第三阶段：把 rubric 放在控制环而非最终裁判位置

按顺序读：

- *SedarEval*：问题级自适应评分项如何构造。
- *Rubrics as Rewards*：结构化 rubric 如何成为优化信号。
- *OpenRubrics*（ACL 2026）：如何规模化生成并过滤 rubric。

实验中仍需保留固定测试集、可验证任务指标和人工抽查。动态 rubric 可控制某条教学经验是否写入、合并、降权或遗忘，但不应成为唯一的最终评价者。

## 第四阶段：从经验到可迁移 Skill

结合原库已有论文一起读：

- *Agent Workflow Memory*（原库，ICML 2025）
- *ExpeL*（原库，AAAI 2024）
- *Voyager*（原库，TMLR 2024）
- *Memp: Exploring Agent Procedural Memory*
- *Agent Memory Distillation*
- *AgentFly*

重点比较：经验选择标准、抽象粒度、版本更新、弃用机制、冲突检测，以及弱模型/新任务上的迁移。

## 第五阶段：落到 susuAgent 教学场景

优先读：

- *SocraticLM*（NeurIPS 2024）：苏格拉底式教学和不同认知状态学生。
- *EducationQ*（ACL 2025）：教师—学生—评估者多 Agent 教学能力评测。
- *IntelliCode*：集中式、版本化 learner state。
- *Simulating Classroom Education with LLM-Empowered Agents*（NAACL 2025）。
- *GenMentor*：目标导向的个性化多 Agent 教学流程。

建议将教学记忆至少拆为四类：学生状态、题目知识、教学经验、失败经验；每类分别记录来源、时间、置信度、适用条件、冲突关系、最近效用和版本状态。

## 最小可发表实验矩阵

| 维度 | 建议设置 |
| --- | --- |
| 记忆基线 | No Memory / Full Context / Vector RAG / Structured Memory |
| 生命周期 | 只写入 / 写入+更新 / 写入+更新+遗忘 / 学习式全生命周期 |
| 控制信号 | 相似度 / 固定规则 / 固定 rubric / 动态 rubric + 外部结果反馈 |
| 长期压力 | 学生能力变化、误概念修正、旧策略失效、冲突证据、跨题迁移 |
| 外部指标 | 正确率、提示泄露率、学习增益、状态估计误差、冲突修复率、token、延迟 |
| 泛化 | 新学生、新题型、新课程、较弱模型、跨 Agent 复用 |

最值得优先验证的失败现象是：旧学生画像或旧教学策略已经失效，但相似度检索仍把它们反复召回，导致后续教学持续偏离。这个现象能够自然连接“更新/遗忘”“动态 rubric”和“长期教学效果”。
